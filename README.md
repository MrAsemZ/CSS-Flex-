# CSS Flexbox Exercises

A collection of **12 exercises and designs** created to practice and improve CSS Flexbox skills.

## Technologies

* HTML5
* CSS3
* CSS Flexbox

## About

Each exercise focuses on different Flexbox concepts such as:

* Flex direction
* Alignment
* Spacing
* Wrapping
* Positioning elements
* Creating different layouts

## How to Run

Open any exercise's `index.html` file in your browser.
